# Агент Neural Tower

Интеллектуальный ассистент для разработки в VS Code на базе локальной модели Neural Tower. Это самостоятельный проект: каркас написан с нуля, архитектура и компоненты перепроектированы заново, без заимствования кода из других решений.

Агент подключается к серверу SGLang/vLLM, выполняет чтение и запись файлов, поиск кода, выполнение команд оболочки и генерацию сообщений коммитов.

## Системные требования

- VS Code версии 1.85.0 и выше
- Node.js версии 20.0.0 и выше
- npm или аналогичный менеджер пакетов
- Доступный сервер SGLang/vLLM с API, совместимым с OpenAI

## Установка зависимостей

```bash
npm install
```

## Сборка

```bash
build.bat
```

Скрипт выполняет проверку типов TypeScript, компиляцию через esbuild и упаковку в файл `nt-agent-0.1.0.vsix`.

## Очистка

```bash
clean.bat
```

Скрипт удаляет скомпилированные файлы (`out/`), пакеты VSIX, промежуточные директории и журнальные файлы.

## Установка расширения

После сборки установите VSIX-файл в VS Code:

```bash
code --install-extension nt-agent-0.1.0.vsix
```

Или через интерфейс: **Расширения** > **⋮** > **Установить из VSIX**.

## Настройка

Откройте настройки VS Code и выполните поиск по запросу `Агент Neural Tower`. Основные параметры:

- **Адрес сервера Neural Tower SGLang** — URL сервера вывода (по умолчанию `http://localhost:30000`)
- **Имя модели по умолчанию** — идентификатор модели (по умолчанию `qwen3.6-27b`)
- **Максимальное число повторов** — число повторов запросов при ошибке бэкенда
- **Тайм-аут запроса** — предел времени ответа в миллисекундах
- **Автоодобрение небезопасных инструментов** — отключение запросов разрешения для инструментов из белого списка

## Горячие клавиши

| Сочетание | Действие |
|-----------|----------|
| `Ctrl+Shift+A` | Перейти к полю ввода чата |
| `Ctrl+Shift+E` | Объяснить выделенный код |
| `Ctrl+Shift+F` | Исправить выделенный код |
| `Ctrl+K Ctrl+A` | Добавить выделение в контекст |
| `Ctrl+Shift+U` | Новый чат |

На macOS вместо `Ctrl` используйте `Cmd`.

## Встроенные инструменты

- **read_file** — чтение содержимого файлов
- **write_file** — запись содержимого в файлы
- **edit_file** — точечная замена текста в файлах
- **bash** — выполнение команд оболочки
- **glob** — поиск файлов по шаблону
- **grep** — поиск содержимого по регулярному выражению
- **web_fetch** — загрузка содержимого по URL
